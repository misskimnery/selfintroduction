## 5. 방명록 기능 상세 (Supabase)

**테이블 `guestbook`**

| 컬럼 | 타입 | 비고 |
|---|---|---|
| `id` | `uuid` | PK, `gen_random_uuid()` |
| `name` | `text` | not null |
| `message` | `text` | not null |
| `created_at` | `timestamptz` | default `now()` |

**RLS 정책** — `anon` 역할에 `select`, `insert`만 허용. `update`/`delete` 정책 없음(= 불가).

**작성 (Create)**
- 입력: 이름(1~20자), 메시지(1~200자)
- 클라이언트 + 서버 양쪽에서 빈 값 / 길이 검증
- Server Action으로 insert → `revalidatePath('/')`
- 전송 중 버튼 비활성화, 실패 시 인라인 에러 문구

**목록 (Read)**
- `created_at DESC`, 최근 **50개**
- 항목당: 이름, 메시지, 상대 시간(예: "3시간 전")
- 비어 있을 때: "첫 방문자가 되어주세요 🙌"

## 6. 기술 스택

- **Next.js 15 (App Router)** + TypeScript
- **Tailwind CSS** (별도 UI 라이브러리 없음)
- **Supabase** (`@supabase/supabase-js`) — DB만 사용, Auth·Storage 미사용
- **Vercel** 배포
- 환경변수: `NEXT_PUBLIC_SUPABASE_URL`, `NEXT_PUBLIC_SUPABASE_ANON_KEY`

## 7. Non-goals (이번 2시간에 **하지 않는 것**)

- ❌ 로그인 / 회원가입 / 인증 — 방명록은 익명 작성
- ❌ 방명록 **수정·삭제·답글·좋아요·페이지네이션**
- ❌ 관리자 페이지, 스팸 필터, 캡차, 욕설 필터링
- ❌ Supabase Realtime 실시간 구독 (작성 후 revalidate로 충분)
- ❌ 다크모드 토글, 다국어(i18n)
- ❌ `/` 외의 추가 라우트 (블로그, 프로젝트 상세 등)
- ❌ 애니메이션 라이브러리(Framer Motion 등), 스크롤 인터랙션
- ❌ 이미지 업로드 기능 — 사진은 정적 파일로만
- ❌ OG 이미지 자동 생성, 고급 SEO, 애널리틱스
- ❌ 이메일 알림, CMS 연동
- ❌ 테스트 코드, 디자인 시스템 구축
